Methods

What this is

Burn Calendar tracks California fire activity one day at a time and places it on a single, consistent scale across the whole VIIRS era (2015–present). Every day with reported science-quality detections of fire by the Suomi NPP VIIRS instrument is converted to the number of 1 km² grid cells a MODIS‑Aqua image would have shown occupied, using a model fitted specifically for California. The number answers: how much fire, how concentrated, where, and how it builds and falls within the season — day by day, since 2015.

The calendar is rebuilt every morning by an automated job. It is an activity index: it does not measure acres burned, count distinct fires, or predict escape.

Definitions & units

  • Activity — predicted MODIS‑Aqua occupied 1 km equal-area grid cells per pass, summed across a day. The grid is cylindrical equal-area (x = R·longitude, y = R·sin(latitude)); cell shapes distort toward the poles only.
  • FRP — fire radiative power in megawatts, summed across the day's cells; a measure of energy release rate, not extent.
  • Reported days — days on which VIIRS S‑NPP produced science-quality (or near-real-time) detections. A blank dashed cell means no observations were reported for that day; it does not mean zero fire.
  • C6 / C6.1 — NASA MODIS Collection 6 and 6.1 reference epochs. The absolute levels differ between collections; the model carries an epoch indicator so each day is scored against its own reference collection.

Data sources

  • NASA FIRMS area API — VIIRS_SNPP_SP (standard processing, quality‑filtered) and VIIRS_SNPP_NRT (near-real-time), statewide bounding box (west −124.4°, south 32.5°, east −114.1°, north 42.0°).
  • The archive from 2015 through the latest published science month was bootstrapped from the CC0 Source Cooperative FIRMS mirror (NASA LANCE republished verbatim), cross-checked row-for-row against FIRMS API extracts of the same windows.
  • Science-quality SP products trail real time by roughly 2–4 months; recent months are served from NRT and upgrade in place to SP as the science files are published. Days currently served from NRT are labeled as such in the day view.
  • Cleaning is conservative and identical across history: vegetation-type detections only (type = 0), VIIRS confidence nominal or high, 10-minute overpass windows, 1 km grid occupancy.

The model

A California-tailored Poisson GLM with log link, fitted against 682 co-detected S‑NPP/Aqua overpasses (10-minute coincidence window, same footprint rules as the archive), 2015–2026. Features: occupied cells, cell and pixel FRP quantiles, zero-FRP fraction, cell neighborhood and 5×5 coarseness fractions, scan/track, thermal medians (ti4), local solar hour and day-of-year (circular), day/night, and an epoch indicator (C6.1 from 2023). Ridge penalty λ = 1.0; coefficients and feature standardization ship in this repository (pipeline/model/ca_model.json).

The VIIRS/MODIS count ratio differs sharply by collection (~0.26 in C6 vs ~0.42 in C6.1 summed over the cohort), so a single global constant systematically fails by epoch. Validation is leave-one-year-out: every season is scored by a model that never saw it.

Updates

Every day at 07:23 UTC, a GitHub Actions job pulls the current year's SP window in 5-day chunks (backfilling months as NASA publishes them) plus a trailing 120-day NRT window, re-aggregates, re-scores, and commits the rebuilt docs/data/calendar.json. The site is fully static; all scoring happens ahead of time. Nothing about you is measured or stored — there are no cookies and no analytics on this page.

Fine print

  • VIIRS S‑NPP remains the deep-time reference; NOAA‑20/21 are not yet harmonized into this product and MODIS science collections end in 2026 — the MODIS‑Aqua scale is used here as a fixed historical reference, not an ongoing sensor.
  • Early November 2026 shows only the days reported so far; months with pending science reprocessing upgrade automatically as NASA publishes.
  • Blank cells are unreported, not zero. Detection geometry (scan edge, off-nadir view) and sensor response differences are why the harmonization model exists.

Code, pipeline, coefficients, and the open data file: github.com/yashneil75/burn-calendar. The underlying detections are NASA's public-domain FIRMS products.
